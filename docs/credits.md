# Credits and references

## Project

**Zombie Apocalypse** was created by Joe O'Regan as a college Digital Game Engines project.

## Technology

- Unity game engine
- Unity Standard Assets, including the first-person controller and cross-platform input examples
- Unity NavMesh for zombie movement
- Unity Animator controllers for character, weapon, objective, and door animations
- Unity audio mixer and 3D audio systems

## Art and animation

The report documents the use of free assets and Mixamo character/animation resources. Some models, textures, animations, and environment assets were adapted and assembled for this project inside Unity.

## Music and sound

The project includes an original soundtrack and custom gameplay sound effects, alongside imported effects used for weapons, zombies, doors, and environmental interactions.

## Documentation source

The longer design and implementation report is stored in the repository's `dev/` directory. It includes the original design goals, feature inventory, screenshots, development notes, and appendices.
