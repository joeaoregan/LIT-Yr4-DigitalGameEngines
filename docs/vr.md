# VR experiments

VR support was one of the original design goals, particularly for the Oculus Rift. The project includes early experiments with gamepad input, touch-controller layouts, world-space UI, and first-person movement.

## What was explored

- Replacing keyboard and mouse movement with gamepad or touch-controller input.
- Testing the right thumbstick as an alternative camera control.
- Moving information panels into world space so they can be read in a headset.
- Adding world-space health, headshot, score, and objective canvases.
- Testing the project with an Oculus Rift setup.

## Limitations

VR was not completed as a separate polished mode. Some UI remains designed for a normal screen, and precise aiming and camera movement can feel different from keyboard/mouse play. The current public-facing build should be treated as a desktop/WebGL game rather than a finished VR release.

The original report's design-document screenshots contain the detailed controller layouts and VR experiments.
